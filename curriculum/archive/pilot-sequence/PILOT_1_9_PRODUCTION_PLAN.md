# Phase 2C pilot production plan

The approved `lesson-map.json` fixes the objectives, subjects, order, and 45-minute target for Lessons 01–09. The lesson schema is versioned for `published` content while retaining the exact Phase 1 fixture label. Each author follows map → private quick reference → targeted book analysis → original page only if a detail remains uncertain. Lessons are original adaptations; source concept, locator, and exercise IDs stay in internal provenance.
