# Archived curriculum planning material

**Historical only. Nothing in this folder is a current curriculum source or production instruction.** The canonical proposed course sequence is [`../CORE_DRAWING_MAP.md`](../CORE_DRAWING_MAP.md), a 130-lesson graphite plan awaiting human approval. Course-level research and reconciliation are in [`../CORE_DRAWING_REDESIGN.md`](../CORE_DRAWING_REDESIGN.md); visual plans are in [`../CORE_DRAWING_VISUAL_MANIFEST.md`](../CORE_DRAWING_VISUAL_MANIFEST.md). The former 93-lesson architecture is superseded and recoverable from Git history.

- `phase-2b/` holds the superseded 72-lesson plan, generated maps/audits, decision record and legacy generator. Its lesson numbers, flower requirements, charcoal progression and project count must not be reused.
- `pilot-sequence/` holds historical pilot production/handoff documents. The detailed pilot lesson JSON/assets still exist under their old IDs; the canonical map moves/merges their concepts but does not change those files.

Do not import archived JSON into active code or regenerate it. Private books, extracts, analyses, research and scratch work remain under `sources/`, outside this public archive and all deployments.
