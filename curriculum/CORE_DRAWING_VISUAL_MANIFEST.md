# Core Drawing — visual manifest and production prompts

**Planning only:** this manifest serves the canonical proposed 130-lesson sequence in [CORE_DRAWING_MAP.md](CORE_DRAWING_MAP.md). No images are generated or integrated in this pass. IDs below match the map. Existing pilot JSON/assets retain legacy IDs and remain prototype/reference material; they do not constrain these plans.

## Production direction

Create original ArtApp instructional visuals with graphite-on-paper character: varied pressure, quiet grain, light proposals, selective darker corrections, restrained annotation, and phone-sized margins. Early examples stay simple and visibly in progress; later examples may be more resolved while retaining evidence of observation. Avoid polished posters, fake paragraphs, color, charcoal, uniform digital strokes, copied book illustrations, and marks that hide the teaching point.

Use deterministic SVG or another precise method when ellipse geometry, axes or perspective convergence require accuracy. Pair geometry with observed drawing when a diagram alone could be mistaken for a rule that overrides the subject. Use ArtApp-made or appropriately licensed references with stable viewpoint, full contour/ground contact and believable light. Human references show clothed adults with varied bodies and poses; use consented/licensed production or self/mirror routes. No lesson requires another person.

One planned ID identifies a lesson's principal visual role; it does not require a separate image file if a compact sequence or approved original asset teaches the same decision. Life lessons need a reproducible setup or named reference fallback in the lesson flow, but do not automatically add a second photo to every lesson. Record provenance and useful final alt text for every eventual asset. Keep private books, extracts, analyses and source images under sources/ and out of public assets/deployment.

Each table row gives the visual ID, an original production prompt and the intended alt-text content. Prompt language specifies a learning decision, not a finished image style; apply the production direction above.
