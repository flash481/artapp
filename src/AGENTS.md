# Application implementation

**Default implementation worker: Luna Max** (`gpt-6-luna` at max reasoning when selectable). Luna handles components, responsive layouts, content rendering, local progress, assets, build configuration, accessibility, and routine refactors. The model identifier is a task/agent choice, not repository routing configuration.

Reserve **Sol High** (`gpt-6-sol` at high reasoning when selectable) for genuinely difficult architecture choices, systemic bugs, major UX decisions, or cross-cutting changes where stronger reasoning helps.

Keep the app lightweight, static, data-driven, and mobile-first: the learner reads on an iPhone, draws, and glances back. Preserve clear typography, generous spacing, touch-friendly controls, portrait usability, and safe-area support. Keep course content separate from UI. Do not add a backend or account system, and never place books, raw extracts, private notes, or source-image collections in the app or public build. The site currently has no password gate. See `docs/DEPLOYMENT.md` and `docs/ASSET_STANDARDS.md` for project-specific conventions.
