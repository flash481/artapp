# Lessons 1–9 visual direction audit

## Scope and source-image inspection status

This historical pass documented the original pilot order, objectives, exercises, and teaching schema. It changed the drawing language of those prototype visuals: pencil-on-paper demonstrations became the default; technical diagrams remained as precise companions where they clarified construction or eye level. It does not set visual direction or asset requirements for the proposed 130-lesson sequence; see the current visual manifest.

Implementation is complete for the visual pass: 36 original graphite-style examples are integrated across Lessons 1–9; 34 older lesson SVGs were retired; the precise cup-volume and eye-level ellipse diagrams remain alongside new drawn examples. The three generic SVG diagrams remain development fixtures. Every generated image has a matching provenance record under `curriculum/assets/`.

The project currently contains no source books or extracted page images. `sources/books/`, `sources/extracted/`, and the other private source folders contain only `.gitkeep` files. Consequently, none of the cited book pages or their illustrations could be inspected in this pass. The references below identify candidate page ranges already cited by each lesson; they are inspection targets, not claims that an illustration was seen. No source-book image is selected, copied, or rejected on visual merits until those actual pages are available. This limitation should be cleared before a definitive source-image selection audit.

All replacement drawings specified here are original ArtApp demonstrations. Their subject, staging, layout, and annotations are independently composed; the cited books inform the teaching idea only. No source illustration is to be traced or used as a generation reference.

## Replacement visual briefs

### Shared ArtApp drawing language

Use graphite pencil on warm, lightly textured sketchbook paper; monochrome, mostly unrendered, with visible searching marks, light construction, a few erased/corrected lines, varied pressure, and a darker selected contour. Keep subjects simple and achievable. Teacher arrows and measurement guides should look lightly pencilled over the drawing. Keep annotations sparse and readable; do not rely on generated lettering for essential information because the lesson caption carries exact wording. No vector-style icons, perfect geometry, glossy rendering, decorative background, photorealistic finish, or source-image imitation. Provide generous contrast and uncluttered composition so the sketch reads at phone width.

Every file below is an original generated teaching example for public deployment after review. Keep no source scan, source illustration, or raw book material in `public/`.
